# 01 世界观与空间设定 ·《猫眼之后》

> 用途：为分镜、提示词与音效设计提供唯一事实源。所有画面与声音都必须能在本文件中找到依据。
> 约束：当代都市、老公寓 7 楼、无超自然；单章 12 个节点，单镜 6–8 秒，480p 草稿。

## 1. 世界规则

- **时代与地点**：当代（智能手机、业主群、外卖与网约车均存在），中国某二线城市老城区；一栋 1990 年代建成的 7 层老公寓，一梯四户。
- **无超自然**：没有鬼、没有预知、没有时间循环。所有异常都有物理来源：声音来自管道、墙体、电梯井与人的动作；猫眼的鱼眼畸变是光学现象，不是“异世界视角”。
- **物理可信**：老楼隔音差，走廊说话在室内能听清七成；门缝约 8 毫米，光与气味能透进来；电梯会停层、会故障，但不会自己“闹鬼”。
- **信息限制**：沈砚始终在 703 门内，看不到 704 室内；观众与沈砚的信息量一致，不提供“上帝视角”。
- **警方响应**：老城区夜间警力有限，从报警到到场约 8–10 分钟；这构成“十分钟”的叙事压力，而不是精确倒计时。
- **手机信号**：走廊信号弱，靠窗的客厅有 4G；业主群消息可以发出，但电话可能断断续续。
- **暴力尺度**：PG-13。尸体、血迹只以遮挡、轮廓、暗色液体与角色反应暗示；不出现伤口特写与施暴过程。

## 2. 空间地图

```text
                        7F 平面（一梯四户）
        ┌──────────────────────────────────────────┐
        │                 电梯厅                    │
        │        [客梯]        [消防梯/垃圾道]       │
        │           │                               │
        │   ┌───────┴────────────────────────┐      │
        │   │  走廊（L 型，应急灯 ×3）         │      │
        │   │ 701      702      703     704   │      │
        │   │                  ▲        ▲     │      │
        │   │                沈砚      周启明  │      │
        │   └─────────────────────────────────┘      │
        └──────────────────────────────────────────┘

703 户内：防盗门 → 玄关（鞋柜/挂衣钩）→ 客厅（沙发/落地灯/窗）→ 阳台
704 户内：不可见。仅门缝光、门内脚步、拖行声、敲击声与气音可用
猫眼视角：703 门内向外，鱼眼 180°，边缘畸变，夜间偏绿
```

- **703 玄关**：主战场。防盗门、猫眼、门链、鞋柜、挂衣钩、地垫；宽度仅容两人错身，制造压迫。
- **703 客厅**：信息补给点。手机充电位、业主群、靠窗能听见警笛；与 704 共用一堵墙，能听见拖行与敲击。
- **走廊**：L 型，长 12 米，三盏绿色应急灯；703 与 704 门对门，距离 2.2 米；走廊尽头是电梯厅。
- **电梯厅**：客梯一部、消防梯常闭；电梯停层提示音是判断“周启明是否离开这层”的唯一听觉线索。
- **704 门口**：门垫、门缝暖光、门把手上的旧划痕；不拍室内。
- **声音路径**：拖行声经楼板与门缝传入 703；电梯钢缆声经电梯井传到客厅墙角；警笛从南侧主干道传来，经阳台窗进入。

## 4. 声音设计清单

| 声音 | 物理来源 | 听感 / 混音 | 出现节点 |
|---|---|---|---|
| 拖行声 | 地毯纤维摩擦老木地板，重物间歇性磕碰踢脚线 | 低频 60–120Hz，1.5 秒一次，由远及近；不要做成“摩擦怪兽” | s01、s02 |
| 电梯停层 | 老式客梯“叮”声 + 钢缆绷紧 + 门轨摩擦 | 单声、干、略失真；停层后长时间无开门声 | s07 |
| 敲门 | 掌根叩防盗门，三下一组，间隔 0.7 秒 | 中低频，门板共振；第二次比第一次重 | s03、s09 |
| 呼吸 | 门缝里传来的压抑气音 | 近讲、气声大于声带音；几乎听不清字 | s05、s09 |
| 警笛 | 南侧主干道，两辆警车由远及近 | 先只留高频，逐渐加入低频；始终不“贴脸” | s08、s10、s11 |
| 地毯下敲击 | 指节从地毯下顶木地板，三下 | 闷、短、被织物吸收；与敲门形成“里/外”呼应 | s05 |
| 手机震动 / 群消息 | 玄关鞋柜上的手机 | 短促、两次；屏幕亮起照亮天花板 | s08 |
| 室内底噪 | 冰箱压缩机、楼道风声、远处车流 | 贯穿全片，音量极低；静场时反而更响 | 全片 |

**声音规则**：不做 jump scare 爆音；不突然提高总音量；不用高频尖啸；所有惊吓来自“声音出现的位置不对”，而不是“声音突然很大”。

## 5. 光源与色板

| 光源 | 位置 | 色温 / 颜色 | 叙事作用 | 出现节点 |
|---|---|---|---|---|
| 走廊应急灯 | 走廊天花板 ×3 | 冷绿 `#7FA88C`，低照度 | 把走廊变成“非日常”的绿色隧道 | s02、s03、s09 |
| 门灯 | 703 / 704 门框上方 | 暖黄 `#E8A34B` | 门内是家，门外是危险；门缝光即边界 | s03–s06、s09 |
| 客厅落地灯 | 703 沙发旁 | 暖白 `#F2D3A0`，2700K | 唯一的“安全光”，随剧情逐渐被关掉 | s01、s06、s08 |
| 手机屏幕 | 玄关鞋柜 / 沈砚手中 | 冷白 `#DDE7F0`，6500K | 信息与证据；也是暴露位置的 risk | s05、s08、s10 |
| 电梯指示灯 | 电梯门上方 | 琥珀 `#D9A441` | 楼层数字停在 7，说明周没走 | s07 |
| 警灯 | 楼外主干道，经窗帘 / 猫眼反射 | 红 `#C0392B` / 蓝 `#2E5FA3`，频闪 | 外部秩序逼近；照出沈砚的犹豫 | s10、s11 |

**色板总则**：深灰 `#3A3D42`（沈砚）+ 冷绿 `#7FA88C`（走廊）+ 暖黄 `#E8A34B`（门灯）+ 暗红 `#5A1F24`（地毯，只做点缀）。高光比、低饱和，避免大面积纯红。

## 6. 摄影与剪辑规则

- **视角**：全片第一人称限制在 703 门内；猫眼镜头用鱼眼畸变，边缘暗角；不出现 704 室内。
- **机位**：玄关固定机位为主，少量手持跟拍；每个节点最多 1 次镜头运动，避免生成漂移。
- **构图**：门框、猫眼、门缝三条竖线反复出现；人物永远被门框切掉一部分（“看不全”）。
- **剪辑**：硬切为主，不用花哨转场；声音可以跨节点延续（拖行声从 s01 延续到 s02）。
- **禁用**：不拍血腥特写、不拍尸体正面、不做突然贴脸惊吓、不用抖动镜头模拟“鬼”。

## 7. 与生产管线的约束

- 12 个节点、单镜 6–8 秒、480p 草稿；两个结局各 1 个 `ending` 节点。
- 场景只在 703 玄关 / 客厅 / 走廊 / 电梯厅切换，704 室内不建模。
- 无特效镜头：血迹用暗色液体、地毯遮挡与反应镜头暗示；警灯用真实反光或后期色片（待核实）。
- 提示词必须复用 `02_characters.md` 的角色描述块；首尾帧同机位、同光位。
- 资产命名遵循 `assets/frames/<chapter_id>/<node_id>_first.png` / `_last.png`，视频 `assets/videos/<node_id>.mp4`。
- 生成前先过 `validate_graph.py --strict` 与用户成本确认；未确认不调用 ComfyUI。
